# Kadena Wallet

Self-custody desktop wallet for Kadena (KDA). Native installers for Windows, macOS, and Linux. Open source under the MIT License. Built and maintained by KADENA WALLET LLC, a Florida company formed December 2, 2025, after the Kadena Foundation announced its dissolution and the Chainweaver wallet repository was archived.

Website: https://kadenawallet.io

## Why Kadena Wallet

Kadena Wallet exists because KDA holders needed a maintained first-party desktop client. The wallet is non-custodial. Private keys are generated on the user's device, encrypted at rest with a user-chosen passphrase, and never transmitted. The codebase is MIT-licensed and publicly auditable, and an independent third-party security audit has been completed.

- Full 20-chain Chainweb support with automated cross-chain SPV transfers
- Native Ledger Nano S Plus and Nano X integration via WebHID
- One-step seed import from Chainweaver (custom derivation), eckoWALLET (BIP39 12-word), and Koala Wallet (24-word)
- Marmalade / KIP-0011 NFT viewer
- DeFi position dashboard covering eckoDEX and KDSwap
- No third-party analytics, no behavioural tracking
- Free under the MIT License; only standard Kadena network gas applies

Read the full product overview at https://kadenawallet.io/kadena-wallet, or jump straight to the installers at https://kadenawallet.io/download.

## About
